## 独立 Blind Run 与知识重编译

首个基线建立后，又用**只给 query、不暴露 `reference_anchors` / `success_condition`** 的独立执行上下文复跑同一 6 个 smoke case。该运行比人工对照 anchor 更严格，暴露了三个“答案看起来正确，但知识路由没有完全释放”的问题：

| case | 重编译前 blind | 发现 | 重编译后 blind |
|---|---:|---|---:|
| `find-verification-over-task-success` | 1 | 命中 `Verifiable-Agent-Engineering`，但没有稳定命中 `Evaluation-Integrity`；任务成功与评测完整性之间的关系不够显式 | 2 |
| `find-multi-agent-universal-superiority` | 1 | 能拒绝“多 Agent 普遍优越”，但采用边界、同质化与治理成本没有形成最小充分入口 | 2 |
| `synthesize-productivity-bottleneck` | 1 | 能概念性说出流程/组织/验证，但真实检索路径没有稳定进入 `AI-Labor-Bottleneck-Shift → Agent-First-Process-Redesign → Organization-as-Agent-Harness → Verifiable-Agent-Engineering` | 2 |

其余三个 smoke case 在 blind run 中保持稳定：`find-fde-vs-consulting = 2`、`synthesize-security-responsibility-loop = 2`、`synthesize-demo-to-production-check = 2`。

### 本轮重编译动作

- `Verifiable-Agent-Engineering.md`：新增“任务完成率 ≠ verified execution ≠ trustworthy evaluation”，显式连接 `Evaluation-Integrity` 与 `Agent-Security`。
- `Evaluation-Integrity.md`：把“任务完成率 / benchmark 得分不能单独证明可靠性”提升到 summary 与 description，增强自然语言检索可达性。
- `Multi-Agent-Pathology-and-Governance.md`：新增“多 Agent 不是默认优越解”，把协调、同质化、责任稀释和治理成本收敛为采用判据。
- `Building-Effective-Agents.md`：补 reciprocal boundary，明确“先证明为什么需要第二个 Agent”。
- `AI-Labor-Bottleneck-Shift.md`：新增“模型能力 → 流程重构 → 组织吸收 → verification capacity → Outcome”的四层链。
- `Successful-AI-Deployment-vs-GenAI-Divide.md`：沿 blind run 实际命中的高流量入口补四层链路，使真实检索能继续走到四个稳定 Topic。

### 复测结果

第二轮 blind run 中：

- 可靠性题实际使用 `Evaluation-Integrity.md` + `Verifiable-Agent-Engineering.md`，并明确区分任务完成、verified execution 与可信评测。
- 多 Agent 题只需 `Multi-Agent-Pathology-and-Governance.md` 即可给出“非默认优越 + 何时值得引入 + 新增系统成本”的最小充分答案；单页足够是重编译后的预期结果，不要求为了凑引用数强行再读第二页。
- 企业生产率题最终实际使用 `AI-Labor-Bottleneck-Shift.md`、`Agent-First-Process-Redesign.md`、`Organization-as-Agent-Harness.md`、`Verifiable-Agent-Engineering.md`，形成目标因果链，并保留“这是跨来源结构化综合、非统一随机因果模型”的 evidence boundary。

因此本轮 Delta 是 **Find / Synthesize 的路由关系被 refined**，不是新增外部证据，也不是通过修改 Eval case 来提高分数。`Reuse = 1/2` 与 `reuse_trace_coverage = 4/11` 保持不变；不回填历史 Output 来制造更漂亮的覆盖率。

## 基线结论
