# Designing product simplicity for the AI era

> Canonical source: https://commandline.microsoft.com/design-product-simplicity-seamless-ux-ui-agentic-ai-azure-developer-services-foundry/

## Source locator

- Author: Jenny Lanier Wolski, Principal Design Manager, CoreAI, Microsoft.
- Published 2026-08-31.
- Describes returning to a restructured CoreAI organization in March 2026 and observing:
  - teams already using GitHub Copilot and agents daily;
  - designers moving beyond static mockups/clickable Figma prototypes;
  - some designers contributing directly to production code in VS Code or through GitHub Copilot CLI.
- CoreAI portfolio includes Microsoft Foundry and Azure Developer Services.
- Shared Fluent 2 components were not sufficient to ensure cross-product coherence.
- AI-accelerated building increased the risk that local design choices diverged faster across independently built portals.
- Microsoft CoreAI's product-simplicity framing is described through four disciplines:
  - Decision Making;
  - Engineering Craft;
  - Coherence Making;
  - Product Craft.
- The piece explicitly treats AI as changing both how software is built and who/what consumes the design system.

## Evidence boundary

This is a first-person operating reflection from a current Microsoft design manager, not a controlled productivity study. It strongly supports production-code participation, blurred design/engineering boundaries and coherence as a portfolio-level bottleneck. It does not quantify defect rates, design-review throughput, model-behavior ownership or long-term customer outcomes.
