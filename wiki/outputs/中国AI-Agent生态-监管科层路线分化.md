# 中国 AI Agent 生态：监管重压下的三路线分化

> [!warning] 2026-11-28 知识消化勘误
> 原文依据 7 月模拟推演，将特定服务的监管误写为 Agent 全面禁令，再推导企业竞争终局。撤回社交路线被封死、B 端获得全面豁免、腾讯必然退出、中国没有制度积累、Token FinOps 无 TAM 等命题。保留历史题名及 Git 版本；本文不作当前市场份额报告或法律意见。

## 已核实的监管边界

五部门第21号令《人工智能拟人化互动服务管理暂行办法》2026-04-10 公布，2026-07-15 施行。第二条以面向境内公众提供持续性情感互动为适用条件；不涉及这种互动的智能客服、知识问答、工作助手、学习教育、科学研究等不适用该办法。第三、六条包含创新促进和分类分级治理，第九、十条规定安全责任和全生命周期管理。不能由此推出一般 Agent 禁令或任何企业免除其他法定义务。

一手来源：[正式规章](https://www.cac.gov.cn/2026-04/10/c_1777558395078289.htm)、[官方答记者问](https://www.cac.gov.cn/2026-04/10/c_1777558395284407.htm)。

## 产品事件与因果边界

2026-07-04 新京报报道豆包、千问通知将于 7 月 15 日下线用户自建智能体相关功能。[报道转载](https://cbgc.scol.com.cn/news/7730242)。通知范围与全部 Agent 能力不同；同期青年报标题还称当日千问仍可使用，页面未成功打开，不据此确认最终执行状态。未取得平台完整原始通知、事后功能实测及因果决策记录。法规生效日与调整日期相同不是直接因果证据。

## 三类入口是分析维度，而不是终局

| 入口 | 候选价值 | 需要核验 |
|---|---|---|
| 企业工作流 | 流程、权限、业务系统与结果验收 | 实际采纳、交付成本、接管与安全 |
| 消费与社交 | 分发、用户需求及交互体验 | 具体功能是否涉及持续情感互动、用户权益、真实留存 |
| 开发者工具 | 代码、测试、工具链和可验证交付 | 质量、成本、维护和授权边界 |

同一企业可同时参与多类入口。企业既有生态可能影响策略，却不足以确定监管动机、竞争优劣及未来退出。原文企业 MAU、任务完成率、产品化周期、消费者信任和市场预测未定位可比原始证据，不作为当前事实。

## 组织吸收能力与证据选择

流程可解释性、跨部门协调、权限、预算及责任可能影响 AI 落地，参见 [[AI-Ready-Organization]]、[[Forward-Deployed-AI-Enablement]]。其影响方向和大小需在具体组织中测量；不认定中国企业普遍具有固定三至五年转型周期或某种 KPI 结构。

Token FinOps 需求取决于实际调用规模、成本结构、模型与工作流组合及预算责任，单模型系统同样可以需要成本治理。不能从拟人化服务监管推出中国市场无需求。

中文实践材料的来源选择可能造成观察偏差。应按现行 Schema 寻找一手技术资料、部署证据、失败记录与反例，区分资料缺失和现象不存在；不把报道体裁或地区当作证据强弱的替代指标。

## 治理比较的使用方法

比较具体法规的适用对象、义务、执行与救济机制、实际执法及结果，不把“中国/西方”归为两个单一制度类型。法规文本中的风险治理要求也不等于已证明执行有效。
