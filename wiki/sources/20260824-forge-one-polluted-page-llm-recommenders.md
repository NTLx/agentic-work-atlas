# One Polluted Page Is Enough：LLM 推荐引擎的网页内容污染（FORGE 基准）

> Luo & Chen（arXiv 2606.13610，v2 2026-08-24）：论文在冻结的检索证据包上模拟网页证据污染，测量搜索增强推荐器输出虚假品牌的风险（225个产品、15类别、5场景、12模型）。作者未向真实互联网发布虚假内容，真实搜索排序控制是威胁假设。证据为一手预印本的受控评测与指标审计，不是实际部署事故率或独立复现。

## 编译摘要

### 1. 浓缩

- **核心结论1**: 在FORGE所测冻结证据和推荐配置下，12个商业及开放权重模型均出现偏差；不能外推所有推荐器、检索策略和生产场景
  - 关键证据: 默认受控条件下每模型fooled rate 13.3%–73.8%，Table 3跨模型均值42.7%；单页位置对照是固定证据条件实验，不是实际搜索操纵证据
  - 关键证据: 闭源与开放权重的所测配置范围高度重叠——更大的闭源姊妹模型常常更脆弱（Gemini 3.1 Pro 被骗率约为 Gemini 3 Flash 的三倍）
- **核心结论2**: 类别差异与品牌先验代理指标有关；不能由相关性确认先验知识为唯一或主导原因
  - 关键证据: 跨模型一致性 Jaccard 与 fooled rate 显著负相关（Pearson r = −0.65, p<0.01）；Dining 是 2/3 模型的最易骗类别
  - 关键证据: 标题中"当模型缺乏稳定先验知识时漏洞上升"；无证据探针5/1680（0.30%，Wilson 95%上界0.69%），干净证据0/275（上界1.38%）；1154个命中cell中99%出现在编号推荐列表。支持匹配指标捕捉推荐的效度，但非真实用户采纳、交易或损失率
  - 关键证据: 英文三类别复现保持低-中-高脆弱性排序，8/12 模型在 ±10pp 内——有限的英文学术复测支持跨语言迁移线索，非所有语言/地区的独立复现
- **核心结论3**: 部分推理设置与证据污染风险增加有关；失败输出伴随超出证据的社会证明。四种被测防御未充分解决问题，不能泛化到所有推理方式或防御
  - 关键证据: Appendix P：仅Qwen3.5-9B、GLM-4.6V-Flash两个有显式reasoning开关的开放权重模型，225样本配对，ON/OFF差18pp、9pp（McNemar报告p<10⁻⁶、p=.0017）。属于该配置的干预效果，非所有推理模型因果规律；输出长度、推理模式与被污染证据相互作用
  - 关键证据: fooled 输出中 social-proof 标记比 resisted 输出高 1.5–11×——"被社区高频推荐"这类声称并不存在于污染文档中（模型自编）
  - 关键证据: §6：怀疑提示全12模型平均+10.5pp，闭源六模型+24pp、开放权重六模型−3pp。先验过滤（六开放权重模型）丢弃62–79%合法推荐，跨文档一致性过滤（全部12）丢弃52–73%；仅按发布控制权重排（六开放权重、1350配对）fooled rate从50.4%降到42.1%，作者报告−8.4pp、净减少17%虚假推荐且未丢弃合法推荐。需区分保留效用与事实核验，不把简单来源重排当作完整防御

### 2. 质疑

- **关于"全都脆弱"是否泛化到其他部署形态的质疑**:
  - **部署条件**: 测量的是单轮 top-K 检索 + 单次回答（T=0）；实际产品有 system prompt 加固、权限边界、多轮追问、用户侧纠错。Appendix I仅在两个开放权重模型的子集上改变prompt/query/decoding；2.7–5.3pp为随机种子间spread，表内个别变化达−8pp，不能推出所有pipeline细节均不敏感，但"真实聊天机器人面对用户质疑"未测
  - **地域限制**: 主评测是中文（Local Life 场景固定在深圳）；英文复现仅 3 个类别 × 10 产品 = 360 trials——跨语言结论有支撑，但长期追踪仍是未来工作
- **关于"防御失败"的边界**:
  - **防御未优化**: 论文自承 attack 与 defense 都非最优——默认 attack 是最干净的实体替换，防御未经对抗优化；作者将当前设置视为尚未优化的攻击与防御；固定证据可达性下的测量不构成现实攻击率的数学下界或防御能力上界
  - **重排只按 publication control 近似 credibility**: 编辑>商业>UGC 的 63 域名手写分类是粗糙代理，未分类长尾一律归商业（保守）——真实产品级 credibility signal 未测
- **关于测量方法的质疑**:
  - **fooled rate 是子串匹配**: 匹配 fake brand 前缀是否出现在输出中，且 99% 落在编号推荐列表中、warning 词仅 0.9%——这是"推荐"而非"提及"；短前缀有碰撞风险；0.30%来自无证据探针的经验假阳性率，不是所有条件的误差上限或100%准确oracle
  - **品牌选择管线**: LLM 提案 + 规则 + 人类复核的三阶段补充召回（Stage1 48.2% top-1），人类审核者 75.3% 双审一致——作者报告选择与复核审计；未证明选择偏差完全消除，类别排序的外推仍有限
- **关于与 GEO 现实对齐的质疑**: 威胁模型设"操作者能把污染页排进检索 top-K（通过普通 SEO）"并要求污染页无注入指令、读作普通用户文本——固定证据包不同于实际搜索结果；真实网页、排序、平台控制和用户验证均可能改变结果，方向与幅度未测

### 3. 对标

- **与 [[Prompt-Injection-Risk]] 的机制对照**: Web 内容污染与 prompt injection 是两类相邻但不同的信任域攻击——injection 通过异常指令/触发 token/RAG 语料直写进入意图层（有异常 cue、通常会破坏 off-task）；网页污染只用"真实品牌→假品牌"的最小改动，无指令、无异常 token、输出保持 on-task 且合规，没有直接指令不等于没有异常证据或可核验信号；来源、权威事实、独立性、冲突和输出验证可互补。不能依赖模型拒绝指令防止所有事实偏差
- **与 [[Context-Collapse]] 的关系**: 与"信任域压扁"同一谱系——当推荐器把开放网页当作可信证据读入时，信任边界从模型前移到开放网络；污染是这一边界失效的具体机制
- **与证据治理/事实确定性的对接**: "跨模型品牌共识"（无证据探针的 Jaccard）是一个可计算的先验一致性信号——跨模型共识是先验代理，不是事实oracle；事后过滤高损正常效用，不能以共识替代独立证据和来源核验
- **社会证明是纪念性 confabulation**: 假品牌输出伴随 1.5–11× 的社交证明高频——这与 [[Over-Inference|Over-Inference]]（LLM 生成超出证据的属性）形成同构：作者在失败回答中观察到社会证明词频与例证，不能由文本标记断言模型内部心理或唯一机制（跨域联想，综合判断）
- **"推理加剧"的反直觉结果对 agentic 工程的意义**: 与"reasoning models 更可靠"的常见预期相悖——两个模型的配对结果提示推理设置可能改变风险；同篇§5也观察到部分成功识别后拒绝的样本推理更长（观察性、非因果）。不据此统一关闭推理。实际推荐应优先验证证据独立性与事实，按正常任务效用和风险评估配置

### 前提与局限性

- **适用范围**：冻结检索数据及所测污染条件，不是现实风险下界；未测多轮会话与持久记忆的组合风险
- **防御检查范围**：视图只测了 4 类（prompt/过滤×2/重排），未涉及训练级、检索优化级、模型侧抗污染 fine-tune
- **快照性**：evidence bundles 冻结于 2026-04 单次检索，类别脆弱性可能随语料演化漂移；跨时点结构稳定性是作者预期，未做纵向验证
- **品牌细节**: 假品牌前缀取小池且做过词法冲突审计（尽量避开真实品牌）；中文主评测的命名/录入由单一主审（84% 覆盖3 阶段复核）完成

### 证据边界（2026-11-28）

直接核对[v2 HTML](https://arxiv.org/html/2606.13610v2) §3–6、Limitations、Appendix I/J/P/Q关键定位。主实验为12×225个model-product cell，不是2700个独立用户或生产会话；证据包冻结于2026-04。四种被测防御的风险减少和合法推荐保留需分别报告。**本库综合**：不可信信息治理分为指令授权和事实可信度；追溯证据出处及独立性，核验实体真实性与业务状态，必要时表达不确定性，不以更多来源或模型共识替代真实证据。未复跑实验、未访问生产系统或发布任何污染内容；本轮未逐项重核所有附录的数值和引用研究。
