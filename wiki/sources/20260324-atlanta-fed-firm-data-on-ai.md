# Firm Data on AI

## 编译摘要

### 测量身份

- **单位**：企业高管回答。
- **时间**：2025-11 至 2026-01。
- **状态**：过去三年 = 回溯归因；未来三年 = 预期。
- **分母/权重**：各国调查不同，跨国 pooled 也不是统一人口权重。

### 核心证据

- 作者把过去三年就业影响的 pooled 结果映射为约 0.00%。
- 未来三年的 pooled 就业影响预期约为 -0.68%。
- 同一问卷框架可明确分离 realized-retrospective 与 expected。

### 不可越过的边界

- 0.00% 不是行政工资单意义上的“实际净 headcount 没变化”。
- 未来 -0.68% 是管理者预期，不是实现结果。
- 无共同职业、青年入口、培训完成或独立能力字段。

### 对标

- 对 [[Labor-Market-Impact]]：必须把 realized、retrospective attribution、expected 分列。
- 对劳动证据长表：代表性/调查层与平台样本、行政流量不能直接相加。
