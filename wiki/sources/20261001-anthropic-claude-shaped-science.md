# Claude-shaped science

> External index compile：仅保留可恢复索引与综合摘要；仓库不保存文章全文。精确引用或复核原文时，访问 canonical URL。正文哈希针对完整页面主文（标题至 Disclosure），使用网页正文提取文本，去除网页行号与检索器引用标记后以 LF 连接计算；摘要不包含该全文。

## 编译摘要

### 1. 浓缩

- **核心结论 1：当前 LLM 不适合直接承担“像人类科学家一样提出并判断深层概念问题”的完整角色，但可在问题可形式化、计算过程可编码、结果可复核的任务上形成高效科研工具链。**
  - 关键证据：作者以半数已知结果复现、半数此前未计算的 30 个积分作为例子；他称 Claude 将原本需数周的代码工作缩短到约 20 分钟，并在数周内扩展计算工具。该速度比较是作者自述，不是独立生产率评估。
- **核心结论 2：把模型发现的跨学科“技术可解问题”变成有学科价值的结果，需要领域专家共同改写问题、解释结果并校验意义。**
  - 关键证据：作者称 Claude 在几乎所有案例中技术上正确，但初始结果常不足以引起学科兴趣；森林生态案例中，James O’Dwyer 建议从偏差中提取物种差异信号，种群遗传学案例中 Michael Desai 将关注点从单变异计算引向染色体内变异关联。作者还把 4,452 篇论文的复现包检查、6,072 种语言的重音数据库列为协作案例。
- **核心结论 3：可复用的科研 harness 不只是执行环境，也通过持续积累软件、协议和校验手段降低跨项目复用成本；人仍需负责问题选择、结果判断、外部验证与贡献归属。**
  - 关键证据：作者描述每项目隔离会话、主会话协调计算和验证结果，另设代码验证及 adversarial referee 工作；同时列出 Agent 过早宣告完成、监控不可信、结论错误、偏好旧问题和无效长时间计算等失效模式。文章结尾强调科学进展仍依赖真实数据的获取、理解和检查。

### 2. 质疑

- **关于科研成果和速度的质疑**：这是参与者的回顾性叙述，项目、基线和成功案例由作者选择；没有统一任务集、独立复现率、成本核算或失败项目分母。文中提到 400 个候选问题、36 篇稿件、18 个领域及 19 位合作者，但这些规模数字不能单独证明产出质量或可迁移的效率提升。
- **关于跨学科正确性的质疑**：多处结果处于继续探索与验证阶段。专家参与改善问题相关性，并不等于所有结果已经过同行评审、独立数据验证或领域共识确认；具体结论应回到文中链接的论文、数据集和项目材料核验。
- **关于“问题适配”的质疑**：可形式化、可执行代码和可数值复核是文中案例的共同特征，但该样本偏向定量计算及可数字化文献数据。不能据此推断实验设计、田野观察、临床决策或理论构造等不可压缩任务同样容易自动化。
- **关于人的角色变化的质疑**：作者主张人更多承担概念工作和指导，但没有测量这些工作所需的专业训练、责任分配或科研职业路径变化；模型能执行技术步骤不代表监督成本消失。
- **关于署名与贡献的质疑**：文章明确提出贡献和署名问题，但未提供解决规则。应区分工具贡献、可验证的知识贡献、责任承担与作者资格，不能由单篇作者观点直接得出规范结论。

### 3. 对标与约束

- **跨域关联（综合判断）**：BootLoops 的演化类似工程 harness 的“把一次性成功变成可复用能力”：每轮计算暴露缺口后，补充可复用代码或 protocol；这使工具积累参与问题搜索，而不是只做最后执行。对应 [[Agent-Harness]]，但科学计算的精确数值 oracle 比多数开放式组织任务更强。
- **与专家判断的关系（综合判断）**：本文案例支持将“生成候选/跨域迁移”与“评估学科意义/选择问题”拆成互补工作；它与 [[Judgment]] 相关，但不足以证明判断力已成为唯一或普遍的人类优势。
- **硬约束**：科学结论仍需与现实数据和可检验方法建立联系，计算正确不自动推出解释正确或问题重要。
- **软约束**：代码、数据、论文开放程度及领域专家可用性决定 harness 能否复用，以及验证闭环是否能运行。
- **适用边界**：本文的强案例主要来自高计算量、定量、代码可执行且有数值或数据校验条件的问题；不得外推成 LLM 已普遍能自主进行科学研究。
