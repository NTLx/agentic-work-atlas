### 共识（定理跨域存活并升级：三墙分化 + 中介化定理 + T2 预声明 + 跨域法则 + 封口墙生长定理）

1. **三墙跨域判决**："三道墙全是结构非动机"存活但分化——**量词墙 + 工具墙 = 跨域常量**（形式/金融/工程/医疗四域皆强：修复的存在性不蕴含清偿的全称性；清算工具[验证器/循证医学/最后贷款人货币]全是生成物）；**封口墙 = 跨域变量**，强度 = 现实的中介化程度（形式域 100% kernel 垄断 / 金融 ~95% 内生[现实本身是系统生成的，市场就是系统自己] / 工程 ~50% 自愿建造[中介化 = 结算成本与监控成本的权衡] / 医疗 ~20% 身体直接说话但缓慢嘈杂）；**形式域特有性质：100% 中介化域里递延域内不可见**（无域内提醒信号 = 最危险递延形态，lean4lean 实例：bug 穿"已证明"外衣）。
2. **定理升级 → 中介化程度定理**：递延必然性 = f(中介化程度 × 结算延迟)——高中介 → 递延必然（只有验证器说话）；低中介高延迟 → 递延事实存在（医疗：现实最终结账但账单年级迟到）；低中介低延迟 → 递延仅拖延（经典工程）。定理从"形式域定理"升级为跨域定理。
3. **T2 前瞻预声明（agent 化 = 全域造墙运动）**：agent 通过形式接口行动（API/权限/日志），组织越来越经由 agent 系统与现实交互 = 给一切触及域安装 kernel；agent 密集域将出现（a）现实逐层中介（行为→遥测→指标→声明，每层一个可俘获封口点）（b）递延必然性随中介层数上升（c）清算被推迟且规模放大（明斯基时刻中介化版；金融史校准：2008 = 风险被翻译六层后一次性破墙）；医疗 = 极端案例（新封口 × 高结算延迟 = 递延双重保险）；**证伪条件：agent 密集域维持低延迟直接现实通道，或中介层数与递延无关**。
4. **跨域制度法则**：结算的破坏力 ∝ 1/结算频率，∝ 清算权集中度；防崩 = 小结算常态化 + 清算权多元分布；四域原型同构：金融（存款保险/最后贷款人/倒闭常态化）/ 医疗（M&M 会议/无责难差错报告/执业审查）/ 工程（混沌工程[主动邀请现实进场，最主动原型]/blameless postmortem/error budget/多云）/ 形式域（竞争 kernel/跨实现审查/持续重验/红队文化；反面：单一 kernel 生态 = 全域隐性递延且域内不可见，形式域无生产环境兜底，分散是唯一生存策略）；**垄断清算定义权 = 庞氏充分条件**；agent 域政策含义：造墙必须与小结算制度同步建造。
5. **封口墙生长定理（追本）**：封口墙 = 结算成本的外部化机制（中介化不降低结算总成本只搬迁：现在→未来、我→缺席者，"便宜" = 外部化）；生长原因 = 付账人在决策现场缺席（外部化成本不入造墙算式 = 中介化"个体理性"的全部秘密）；获利结构 = 中介层运营者双重收入（造墙生意 + 不确定性税基，墙 = 收费站）；对抗之根 = 给递延定价 + 给结算打折成对（error budget = 递延定价/配额 = 未来的代理投票权；blameless postmortem = 结算打折；只定价 → 隐瞒，只打折 → 仪式）；底层 = 递延市场结构性缺席付账人（价格永远偏低），一切对抗 = 替缺席付账人代位（error budget 代位未来/监管代位公众/混沌工程代位被递延的大故障/无责难报告代位沉默受害者）；**反效率工程最精确定义 = 故意保留昂贵的直接结算 = 故意不让某个付账人被驱逐出场**。
