# Rachel Laycock（Thoughtworks CTO）

> [!definition] 定义
> **Rachel Laycock** 是 Thoughtworks CTO，2026-08 在 martinfowler.com 的 "Rachel's Ramblings" 发表 "Citizens Build, Agents Execute, Experts Govern"——核心论点：**AI 时代稀缺资源从 coding 翻转到 engineering judgment**，experts 杠杆放大因为 decisions 的下游影响（千 features 共用 platforms/guardrails）；experts 不是被取代而是被 leverage。

## 关键贡献（本文）

- **Citizens/Agents/Experts 三分法**: 不是 role 分类而是 value-flow 框架——citizens 任何能 build 的人 + agents 执行 + experts 治理
- **核心论断**: "Organisations don't run on code. They run on trust."
- **稀缺相变**: engineering judgment 是真正稀缺，过去被 coding scarcity 掩盖
- **experts 杠杆**: from "build every feature" to "design guardrails / platforms / practices / feedback loops"
- **production vs demo**: production 阶段问题（security/resilience/audit/scaling/monitoring）不出现 unless experienced engineer 在场

## 立场偏见提醒

- Thoughtworks 是 enterprise consulting 公司——Rachel 视角偏 enterprise / regulated industry
- startup / scale-up 可能 lean agents + minimal experts 模式——框架适用边界
- "experts 杠杆放大" 主张在 scaling 组织中成立；在 small team 可能直接 expert coding 更高效
- 自我反思："I'm not convinced that was ever the real scarcity"——主张本身有 nuance
