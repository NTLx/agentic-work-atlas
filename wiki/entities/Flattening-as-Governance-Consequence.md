# Flattening-as-Governance-Consequence（去科层化治理后果模型）

> [!warning] 知识身份
> 本页为 synthesized 解释模型，不是经证明的组织定律。“定理”别名仅保留历史兼容性。2026-11-28 撤回组织必然扁平化、控制权反比例公式、固定 conformance gap 阈值与未经因果识别的产业结论；原版可由 Git 恢复。

> [!definition] 当前定义
> Agent 参与执行可能改变信息转译、监督、协调和专业判断的相对成本，使某些管理职能缩减、扩展或重新分布。组织层级是否减少取决于任务结构、授权设计、责任、治理负担与技术及组织环境。

## 候选机制与竞争解释

| 机制 | 可能结果 | 竞争解释或反例 |
|---|---|---|
| 自动化信息汇总及例行协调 | 部分管理劳动减少 | 产出增多导致更多协调、审查和例外工作 |
| 个体执行杠杆提高 | 部分执行与编排职责下沉 | 权限集中、风险增加或跨团队依赖要求新增治理 |
| 共享平台与可复用工作流 | 减少重复集成和管理 | 平台维护、合规、安全及业务语义工作增加 |
| 组织采用新工具 | 工作方式与角色重新分配 | 成本削减、重组、增长与人才政策也可能独立影响层级 |

不完全契约、剩余控制权与交易成本理论是解释视角，不直接推出 Agent 无法被有界授权，或中间层必然消失。形式授权、实际影响力与组织层级是不同变量。新增管理岗位不能自动归为不算反例的“技术编排层”。

## 关键数据点

- [[20260719-if-ai-is-so-great-why-isnt-it-working]]：Varick 供应商文章基于其接触的企业案例，提出 SOP 与实际流程差异及 agent sprawl。原文称 conformance gap 通常 30%+、例外驱动流程可超过 70%，但未提供可比样本、测量方法和阈值试验；不能推导超过 30% 时 Agent 无法替代执行层，也不能从 50–100+ workflows 的示例推导普遍编排层增长率。
- [[20260718-ai-mania-eviscerating-decision-making]]：Ludicity 的咨询经历与匿名访谈提出绩效信号扭曲、激励和组织政治风险。属于选择性观察与作者解释，不是一般失败率或组织扁平化的因果证据。
- [[20260604-anthropic-recursive-self-improvement]]：已有剪藏报告 2026-05 工程师每日合并代码量约为 2024 年的 8 倍。这是内部活动指标，不等于等质量产出、净生产率、固定团队规模或层级变化的证明。
- 旧版列示裁员、薪酬与层级调查的媒体数字，尚未定位完整原始数据及共同的因果口径，不再作为稳定定量支持。裁员不等于层级减少，职级薪酬变化也不等于控制权迁移。

## 证伪路径

预先定义 Agent 使用深度（实际任务及责任分配）、管理劳动时间、管理跨度、实际层级数量、协调与安全治理成本、正式权限及决策影响力。比较任务复杂度、增长阶段、行业、重组和既有管理结构相近的团队，尽可能使用纵向或分期部署数据。

若例行转译劳动减少但管理层级不变或增加，应保留并解释该结果；若在控制混杂后没有观察到相应变化，应拒绝或收窄相关假说。不得仅因新增层级被重新命名、组织未达事后定义的“稳态”而排除反例。

## 前提与局限性

- 各机制的必要性、充分性、方向及相对效应量均未建立。
- 工作自动化、劳动生产率、组织结构与组织权力不应混为单一结果。
- 原先以经济杠杆变化解释 Anthropic 组织设计和人才流入的因果箭头，属于竞争性假设；二手人才综述不能识别因果方向。
- 组织理念、制度、任务与增长同样可能影响结果。委派 UI 和编码能力不直接决定正式责任或组织层级。
