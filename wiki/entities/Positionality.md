# Positionality（位置性）

> [!summary] 一句话
> 用主体所处情境、知识来源及权责关系解释某些信息、判断与行动为何难以直接迁移。早期“位置性统一理论”是本库多轮哲学推演的名称；本页将其收窄为分析框架，非数学定理或对 AI 能力上限的证明。

## 五个分析视角

| 视角 | 候选问题 | 思想线索（非本轮原著核验） |
|---|---|---|
| 经验主体 | 主观体验与可观察行为是否被混为一谈？ | Thomas Nagel |
| 默会知识 | 熟练判断依赖哪些未显式化的实践与反馈？ | Michael Polanyi |
| 社会位置 | 训练、经历、激励与组织关系如何影响判断？ | Pierre Bourdieu |
| 局部知识 | 哪些事实依赖特定时间、场景与访问范围？ | Friedrich Hayek |
| 责任与立场 | 谁定义标准、谁提供信息、谁承受结果、谁可以质疑？ | Donna Haraway |

这五种思想线索不是五位作者共同提出的模型，也未证明彼此正交。“基底不能同时是基底与焦点”等是本库对默会知识的历史阐释，不能用来证明任何机器在逻辑上无法反思自身标准。

## 可迁移性与责任的区分

- **知识与能力**：工具、现场采集、文档、训练、独立反馈可改变信息和技能的可迁移程度；不能凭“具身”或“情境化”就断言某一任务永远只能由人完成。
- **治理与责任**：在具体部署中明确谁有授权、谁可否决、谁负责验收及后果。能力达到标准不等于取得权力；人有责任也不自动具备充分验证能力。
- **可观察与不可观察**：记录或解释并不等于完整内部机制；不因缺乏主观体验证据而断言行为能力不存在，也不由行为表现证明主观体验。

| 应用 | 可检查问题 |
|---|---|
| 软件工程 | 代码来源、测试及部署责任能否独立检查？ |
| 组织部署 | 现场知识如何被捕获、更新及交接？标准化工具何时已足够？ |
| 知识系统 | 信息出处、观察条件与判断标准是否可查、可质疑？ |
| 人的能力 | 辅助任务表现与独立判断/恢复能力是否分别测量？ |

- 早期 5 次以上 deep think 及 2026-06-23 的 18 runs 元总结是内部历史推演数量，不是独立研究、实验样本或共识强度。

## 前提与局限性

- evidence_level: low。思想来源的原著及其释义未逐一核验，内部多轮对话不等于外部复现。
- 撤回旧二分法“可脱嵌即可被 AI 替代、不可脱嵌则必然不能替代”及“AI 无基底、不能改变标准、人类外部必需”的强结论。信息可迁移不等于执行、授权或效果可验。
- 可证伪方向：同任务比较不同现场信息、训练与反馈条件下的验证和迁移能力；如果不在现场的执行者同样达到独立质量、权限及恢复要求，则应撤回该任务必须驻场的推断。
- 保留历史 alias 与 Git 版本，不以理论修辞为事实晋升。
