# Context Rot（上下文腐烂）

> [!definition] 定义
> 在给定模型、任务、上下文构成和生成配置下，随着输入变长、干扰增加或相关状态被替换，模型表现可能退化。上下文容量上限与任务有效上下文长度不同；长度效应、位置效应、信息干扰、摘要遗漏、指令失效与权限风险需要分别测量。

## 关键数据点

- 现有 [[20260702-anthropic-context-engineering]] 描述上下文策展、按需检索、压缩、外部笔记与子 Agent；这是厂商设计实践，不是普遍退化曲线或保证。
- [[20260824-how-long-should-an-agent-live]] 提出日级协调者与短命专用执行者、持久化偏好的设计示例，没有报告该时限的匹配对照或最优值。
- [[20260728-fowler-orchestrator-tax]] 报告一次四子 Agent 编排中，两次整份原始轨迹被装入主线程；作者明确承认没有逐调用成本记账，成本排序为模型自评。共享知识任务是否合并需要比较重复阅读、耦合、等待和协调。
- [[20260708-bun-in-rust]] 的编译错误修复和审查角色是迁移流程案例，不是上下文腐烂测量；不把并发实例数当 worktree 数，或把编译错误数当 rot 指标。
- 早期引用 Lost in the Middle、NoLiMa、Chroma 等研究的本轮回查与版本区别见 [[2026-11-28]] 第四十四轮。相关研究支持特定任务中的位置、长度和干扰效应；不采用旧 30%、1%、300K–400K、MRCR 单点及未验证阈值作为部署标准。

## 机制与诊断

| 对象 | 可能失效 | 验收 |
|---|---|---|
| 输入长度与分布 | 关键信息难定位、干扰项、位置效应 | 固定问题及证据，改变长度、位置和干扰 |
| 检索与组合 | 漏取、误取、版本冲突、相关事实未合并 | 证据召回/准确性、时效、权限、答案质量 |
| 会话状态 | 摘要遗漏、过时偏好、未完成任务遗失 | 关键状态保留、重建与连续执行 |
| 指令与执行 | 约束丢失、超出授权、实际效果不一致 | 约束遵循及独立执行检查、外部终态 |
| 人机协作 | 负担过重、错误未被发现 | 审查召回、误报、接收、响应与恢复 |

Softmax 权重归一化意味着单次指定注意力分布的权重总和为一，不意味着每个 token 的重要性必降或任务正确率单调下降。不同头、层、位置、表示及检索方式可以改变信息利用。有限容量不等于 KL 散度关于长度恒增；不存在本库已证的统一腐烂公式。即使逐层噪声递减，也不足以证明级数收敛，例如 1/n；相关错误、摘要损失与执行风险不能直接相加为同一种噪声。

## 长周期任务的可选设计

| 机制 | 用途 | 需要检查 |
|---|---|---|
| 有界上下文/按需读取 | 减少无关输入、定位权威事实 | 漏召回、读取权限、延迟 |
| Compaction / 外部状态 | 跨窗口继续任务、保留必要记录 | 摘要缺失、可追溯原文、版本及重建 |
| 分解与子任务隔离 | 局部执行、减少重复上下文 | 任务耦合、交接和全局一致性 |
| 多种验证方式 | 发现不同类型错误 | 参考标准、覆盖、共同错误、实际成本 |
| 降级、暂停、接管 | 在质量/权限/状态异常时限制风险 | 真正生效、未完成与未知效果 |

不必所有任务都采用上述机制；编译器、测试、全新上下文及人类摘要均不是 rot-proof。会话重置不等于权限撤销、删除持久记忆或排除投毒；短期指令可通过作用域和到期语义管理。高风险控制状态应有可执行边界，不只依赖摘要完整性。外部记忆可帮助恢复，但也可能引入检索遗漏、陈旧数据或错误持久化。

## 可检验的选择方法

固定模型版本、工具及任务、真实证据与成功判据，分别改变输入长度、无关信息/干扰项、相关证据位置，另做摘要或重置干预。区分 retrieval-only、使用已提供证据的推理及实际动作质量，测成功/拒答/错误、约束保持、恢复成功、总 Token、等待和人工复核成本。采用任务族及多个样本/重复，预先指定可接受边界；不从单个通过/失败样本确定全局上下文阈值。

## 前提与局限性

- 既有来源包含厂商实践、作者自述与历史综合，未得到统一任务/模型下的纵向跨会话对照；本轮没有执行新实验。
- 撤回旧「Shannon/Miller/Simon 三层定理」「多层腐烂栈」「尺度依赖收敛」「双重 Rot 共振」「时间之矢」的定理身份。历史模拟推演不等于原作者主张或数学证明；撤回固定4–8K、200–500次工具调用、10–20倍、50–100轮及指数逃逸等阈值。
- 检索关系错位与长度退化可并存或交互，不以神经心理类比证明统计正交。人类长期能力再生另见 CR-005，不能从上下文长度推断认知退化或人类永久不可替代。
