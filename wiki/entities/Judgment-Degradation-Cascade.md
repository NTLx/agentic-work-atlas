# 判断力退化级联（Judgment Degradation Cascade）

## 核心工作假设

> [!warning] 证据身份
> 本页是跨自动化、技能学习与 AI 使用材料构造的**低证据 synthesized framework**，不是已建立的认知科学定理。下述“级联”“时间尺度”“可逆性”首先应被理解为待检验假设。

本模型假设判断力退化并非单一均匀曲线，而可能由多个反馈与技能机制串联或相互强化。现有证据尚不足以证明固定先后顺序，因此其价值主要是提出可测变量与干预点。

### 判断力四层解剖

以下四层是本库的分析模型，而非已验证的穷尽分类。各层机制、速度、可逆性需要独立测量：

| 层 | 英文 | 功能 | 候选退化机制 | 时间尺度（待测） | 恢复条件（假设） |
|----|------|------|---------|------------|--------|
| **L0** | Anomaly Detection Gut | 模式-后果不匹配的全局警报。预测→后果对照身心回路 | 后果缺失（回路被短路） | 未知；直接反馈减少可能立即发生，但不等于能力瞬时下降 | 需检验重新获得真实反馈的作用 |
| **L1** | Pattern Recognition | Chunk匹配→行动方案自动弹出 | 肌肉退化（检索速度↓）+ 校准退化（模式库过时） | 未知 | 重新练习可能有助恢复，倍数未验证 |
| **L2** | Heuristic Search | 问题空间有意识搜索，satisficing | 肌肉退化（心理模型分辨率↓） | 未知 | 心理模型重建的效果待测 |
| **L3** | Meta-Judgment | "我该何时不信自己/AI"。信心-准确率校准 | 校准退化（信心-准确率映射漂移）+ 摩擦力退化（启动阈值抬高） | 未知 | 需检验独立反馈及重新校准 |

### 历史级联假设（时序参数已退役）

```
后果缺失 ──→ 不对劲感退化 ──→ 摩擦力退化 ──→ 肌肉退化 ──→ 校准退化 ──→ 身份退化
 (t=0)        (周-月)          (分钟-周)       (月)          (月-年)       (年)
   │              │                │              │             │            │
   │              │                │              │             │            └→ 不归点
   │              │                │              │             └→ 信心-准确率脱钩
   │              │                │              └→ Chunk检索速度↓ + 心理模型分辨率↓
   │              │                └→ 判断启动阈值抬高，最低阻力路径绕开人
   │              └→ 预测-后果对照回路被短路，警报失灵
   └→ AI接管判断→行动→后果分配，人从后果回路中被切除
```

图中箭头、时间标签和不归点是历史推演中的候选假设，并非估计参数；不应当作为训练周期或预测阈值使用。各机制可能并行、互相影响、逆序或不发生。

### 零时刻短路假设

一个可检验假设是：当 AI 接管“判断→行动→后果”中的关键环节时，人类获得的直接反馈可能立即减少；但这不等于判断能力会在同一时刻发生阶跃式退化。当前没有纵向实验支持把“首次替代判断”定义为确定的退化零点。

### 三维风险空间

退化风险可按变化速度、恢复难度与检测难度分别描述；三者没有统一量纲或经验证的乘法关系。

最危险的退化 = 慢 × 不可见 × 不可逆的组合：
- **身份退化（待检验）**：时间尺度及报警能力未知（"我不再认为这是属于我的判断"不产生错误/不适）
- **校准退化（待检验）**：反馈不足可能降低误差检测，不能断言不可自检

### 级联干预策略

干预评价应比较客观能力、实际业务绩效与干预成本；保护层数只是本模型的定性提示，不是已验证的效率公式。

- **前端干预候选**：保留独立尝试、错误反馈与独立验证；检验能否改善后续能力。
- **补救候选**：按已习得技能、未习得技能及信心校准分别设计恢复或训练。
- **干预时间**：尚未验证 3-6 个月黄金窗口或 ROI 排序。

### 环境效度调节

级联损失在高/低效度环境中不对称：

| 环境效度 | L0-L2 风险 | L3 风险 |
|---------|-----------|-----------|
| **高效度**（部分消防、ICU、飞行任务） | 可能损失，按任务测量 | 可能损失，按任务测量 |
| **低效度**（部分难预测任务） | 损失或收益均需测量；不能假定为零 | 元判断及责任机制仍须评估 |

低效度任务的元判断、信心与责任机制也值得测量，但不是已证实的损失。

### 可逆性取决于基座状态（非退化速度）

| 基座状态 | 可逆性 | 恢复路径 | 恢复速度 |
|---------|--------|---------|---------|
| **存在** | 待测 | 重新练习 | 无已核验固定恢复倍数 |
| **过时** | 中 | 忘掉旧框架 + 重新练习 | 可能比初始学习更慢（负迁移确信陷阱） |
| **被侵蚀** | 低 | 先修基座（身份重建）+ 再修技能 | 双重恢复 |
| **从未存在** | N/A（退化是虚构） | — | — |

## 代际版本：去技能螺旋（07-22 圆桌）

本实体的四层解剖是**个体时间尺度**的退化（使用者自己的 L0-L3 逐层级联）。07-22 圆桌判定存在**代际版本**——去技能螺旋（Deskilling Spiral：AI 接入门级工作 → 没人打基础 → 能抓错的人从没被培养），两版本共享同一底（增强陷阱：知道答案污染学习），但性质不同（synthesized/medium，来源：[[2026-07-22]] 研究日志）：

| 维度 | 个体版（本实体） | 代际版（去技能螺旋） |
|------|----------------|-------------------|
| 机制 | 使用者 L0→L3 逐层级联退化 | 下一代人 **L3 从未获得**（师徒制结构被拆除） |
| 可恢复性 | 可检验重新练习能否恢复 | 尚未获得的能力应研究后续习得条件，不等于永久不可习得 |
| 警报结构 | 可引入外部检查 | 若内部专家减少，可能降低发现能力；外部监测、审计及训练仍可能发现 |
| 时间尺度 | 待测 | 待纵向检验，非固定十年阈值 |
| 测量 | 可实验（暴露频率标定） | 主流工具结构性失明（测 headcount 不测默会判断存量） |

**代际版的候选机制**：默会知识可能依赖实际参与、示范、反馈与纠错。学徒制是一种传递途径，不是已证明的唯一途径；AI 同样会犯错，辅助是否压缩有价值的练习或提供新的训练机会取决于设计。详见 [[Skill-Atrophy-and-Knowledge-Debt]] 去技能螺旋节。

**实证校准状态**：入门级岗位数量与能力形成属于不同测量对象，不能用一项否定另一项，也不能从研究指标缺失推断政治偏差。D07已核Ramp Table3 +12%为相对同最终强度后采用者的0–24月平均初级log(1+人数)近似估计，非招聘或训练；见 [[20260630-ramp-ai-jobs-firm-spending-workforce]]。

## 关键数据点

- **即时表现与持续努力**：[Liu et al. arXiv:2604.04721v6](https://arxiv.org/html/2604.04721v6)（2026-10-13）三项随机实验合计1222人，约10分钟AI交互后测独立数学/阅读表现与坚持程度；单次会话即时撤除，未测数月技能折旧。实验2整体跳题率差异不显著（p=.239），解题率71% vs77%（p=.019）；直接答案使用分组为自选/横断面观察，不能识别随机干预的中介因果。
- **临床观察**：[Budzyń et al. 2025](https://pubmed.ncbi.nlm.nih.gov/40816301/) 四中心1443次无AI检查，实施前795例/226检出（28.4%），后648例/145检出（22.4%）；差−6.0pp（95% CI −10.5至−1.6，p=.0089），调整OR .69（.53–.89）。前后回顾性比较非随机分配长期暴露，不能排除同期变化、选择等混杂或断言具体技能机制；仅核对摘要，另有勘误未取得全文。
- **退化不可见（待检验）**：自我感知、客观能力、反馈与依赖可能不同步；原综述未定位具体原始测量，撤回其作为普遍加速退化证据。
- **航空自动化类比**：手动技能、异常检测和恢复条件值得分别研究；本页未定位支持固定 3-6 月、2-5 年等时间参数的原始测量，暂不将其作为事实。

## 前提与局限性

- **理论前提**：判断力可分层（Simon 认知架构）+ 专家直觉存在于高效度环境（Klein NDM）+ 自动化引起的技能退化遵循反馈缺失模型（Norman）+ 低效度环境中直觉判断=噪声（Kahneman）——四者综合为级联模型，任何一个前提被推翻则整体需修正
- **经验前提**：级联因果方向（A→B→C→D→E）为理论推导 + 航空/核电站/医学领域类比，尚未在 AI coding agent 场景中经纵向实验验证因果顺序
- **核心局限**：各判断层的基座维持"最小暴露频率"尚未按领域标定；不归点唯一性（身份退化/不对劲感退化）未闭合；环境效度作为调节变量的操作化度量缺失
- **样本偏差**：经验证据来自医疗和航空领域的自动化研究 + 一项通用 RCT（Liu et al.），对 coding agent 场景的外推有效性待验证
